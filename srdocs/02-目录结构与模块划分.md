# 目录结构与模块划分

## 1. 顶层目录结构

```
element-plus-source-read/
├── packages/           # 核心源码包（组件、hooks、utils 等）
├── docs/               # VitePress 文档站点
├── play/               # 本地开发游乐场
├── internal/           # 内部构建与工具链
├── scripts/            # 项目级脚本（版本生成、发布等）
├── ssr-testing/        # SSR 测试用例
├── breakings/          # 破坏性变更记录
├── typings/            # 全局类型声明
├── patches/            # 第三方依赖补丁
├── .husky/             # Git hooks
├── .github/            # CI/CD 与社区模板
├── .vscode/            # VS Code 配置
├── srdocs/             # 项目分析文档（本目录）
├── package.json        # 根 package.json
├── pnpm-workspace.yaml # 工作区配置
├── tsconfig.json       # TypeScript 项目引用入口
├── vitest.config.mts   # Vitest 测试配置
├── eslint.config.mjs   # ESLint 配置
└── ...
```

## 2. packages/ 核心包详解

```
packages/
├── components/         # UI 组件（91 个组件子包）
├── hooks/              # 组合式函数（33 个 hooks）
├── utils/              # 工具函数库
├── constants/          # 全局常量定义
├── directives/         # 自定义指令（4 个）
├── locale/             # 国际化（68 种语言）
├── theme-chalk/        # SCSS 主题样式
├── element-plus/       # 主入口包（整合所有模块）
└── test-utils/         # 测试辅助工具
```

### 2.1 packages/components/ — 组件包

每个组件一个子目录，典型结构：

```
packages/components/button/
├── index.ts            # 导出入口（withInstall 注册）
├── src/
│   ├── button.vue      # 组件模板 + 逻辑
│   ├── button.ts       # Props 类型定义 + Emits
│   ├── use-button.ts   # 组合式逻辑
│   ├── button-group.vue
│   └── instance.ts     # 组件实例类型
├── style/              # 样式入口
├── __tests__/          # 单元测试
└── package.json
```

```
         │                            │
    ┌────▼─────┐               ┌──────▼──────┐
    │components│               │  directives  │
    │ (91 组件) │               │  (4 个指令)  │
    └────┬─────┘               └─────────────┘
         │ 依赖
    ┌────▼──────────────────────────┐
    │  hooks (33)  │  utils  │ constants │
    └────┬─────────┴────┬────┴─────┬───┘
         │              │          │
    ┌────▼────┐   ┌─────▼───┐  ┌──▼──────┐
    │ locale  │   │theme-chalk│  │ 第三方库 │
    │ (68语言) │   │ (SCSS)   │  │dayjs等  │
    └─────────┘   └──────────┘  └─────────┘
```
