# 组件体系分析

## 1. 组件总览

Element Plus 共提供约 **91 个组件**，涵盖中后台开发所需的全部 UI 能力。组件源码统一位于 `packages/components/` 下，每个组件一个独立子包。

## 3. 组件标准结构

每个组件遵循统一的目录结构：

```
component-name/
├── index.ts              # 导出入口
├── src/
│   ├── component.vue     # SFC 组件（template + script setup）
│   ├── component.ts      # Props/Emits 类型定义
│   ├── use-component.ts  # 组合式函数（业务逻辑）
│   ├── instance.ts       # 组件实例类型导出
│   └── constants.ts      # 组件内部常量（可选）
├── style/                # 样式入口（指向 theme-chalk）
├── __tests__/            # 单元测试
└── package.json
```

## 4. 组件注册机制

### 4.1 withInstall 模式

每个组件通过 `withInstall` 工具函数包装为 Vue 插件：

```typescript
// packages/components/button/index.ts
import { withInstall } from '@element-plus/utils'
import Button from './src/button.vue'

export const ElButton = withInstall(Button)
```

`withInstall` 为组件添加 `install` 方法，使其可通过 `app.use()` 注册。

### 4.2 全局安装 vs 按需引入

```typescript
// 全局安装
import ElementPlus from 'element-plus'
app.use(ElementPlus)

// 按需引入
import { ElButton, ElInput } from 'element-plus'
app.use(ElButton)
app.use(ElInput)
```

### 4.3 安装器流程 (make-installer)

```typescript
// packages/element-plus/make-installer.ts
export const makeInstaller = (components: Plugin[] = []) => {
  const install = (app: App, options?: ConfigProviderContext) => {
    if (app[INSTALLED_KEY]) return    // 防重复安装
    app[INSTALLED_KEY] = true
    components.forEach((c) => app.use(c))  // 逐一注册
    if (options) provideGlobalConfig(options, app, true)  // 全局配置
  }
  return { version, install }
}
```

## 5. 组件编写模式

以 Button 组件为例，展示标准编写模式：

```vue
<!-- button.vue -->
<script lang="ts" setup>
// 1. 定义组件名
defineOptions({ name: 'ElButton' })

// 2. 定义 Props（带默认值）
const props = withDefaults(defineProps<ButtonProps>(), {
  disabled: undefined,
  type: '',
  nativeType: 'button',
  tag: 'button',
})

// 3. 定义 Emits
const emit = defineEmits(buttonEmits)

// 4. 使用 hooks
const ns = useNamespace('button')          // BEM 命名空间
const { _ref, _size, handleClick } = useButton(props, emit)

// 5. 计算 class
const buttonKls = computed(() => [
  ns.b(),                    // el-button
  ns.m(_type.value),         // el-button--primary
  ns.is('loading', props.loading),
])

// 6. 暴露实例方法
defineExpose({ ref: _ref, size: _size, type: _type })
</script>
```

## 6. 组件间依赖关系

组件之间存在丰富的内部依赖：

```
Table → Checkbox, Tooltip, Scrollbar, Popper
Select → Tag, Tooltip, Popper, Scrollbar
DatePicker → TimePicker, Popper
Cascader → CascaderPanel, Popper
TreeSelect → Tree, Select
Dialog → Overlay, FocusTrap
Drawer → Overlay
Menu → MenuGroup, MenuItem, SubMenu
Tooltip → Popper
Popover → Tooltip
Form → FormItem (内部组合)
```

## 7. 虚拟化组件

针对大数据量场景，Element Plus 提供了专门的虚拟化版本：

| 标准版 | 虚拟化版 | 说明 |
|--------|----------|------|
| Select | SelectV2 | 虚拟滚动选择器 |
| Table | TableV2 | 虚拟化表格 |
| Tree | TreeV2 | 虚拟化树 |
| VirtualList | - | 底层虚拟列表原语 |
