# 构建与工具链

## 1. 构建系统

### 1.1 构建入口

构建脚本位于 `internal/build/`，通过 `pnpm build` 触发：

```
pnpm build → pnpm run -C internal/build start
```

### 1.2 内部构建包

| 包 | 路径 | 职责 |
|----|------|------|
| `@element-plus/build` | `internal/build/` | 主构建流程编排 |
| `@element-plus/build-constants` | `internal/build-constants/` | 构建路径、包名等常量 |
| `@element-plus/build-utils` | `internal/build-utils/` | 构建辅助工具函数 |
| `@element-plus/metadata` | `internal/metadata/` | 组件元数据生成（用于文档自动补全等） |

### 1.3 构建产物

构建输出到根目录 `dist/`，包含：
- **ESM** 模块格式（`.mjs`）
- **CJS** 模块格式（`.cjs`）
- **类型声明** 文件（`.d.ts`）
- **样式文件**（CSS / SCSS）

### 1.4 主题构建

```
pnpm build:theme → pnpm run -C packages/theme-chalk build
```

将 `packages/theme-chalk/src/` 下的 SCSS 文件编译为 CSS 输出。

## 2. TypeScript 配置

项目使用 TypeScript 项目引用（Project References）进行分域类型检查：

```
tsconfig.json (项目引用入口)
├── tsconfig.web.json          # Web 端代码（components, hooks, utils 等）
├── tsconfig.play.json         # Playground 代码
├── tsconfig.node.json         # Node 端代码（构建脚本、internal 等）
├── tsconfig.vite-config.json  # Vite 配置文件
└── tsconfig.vitest.json       # 测试配置文件
```

类型检查命令：

| 命令 | 说明 |
|------|------|
| `pnpm typecheck` | 运行所有域的类型检查 |
| `pnpm typecheck:web` | 仅 Web 端 |
| `pnpm typecheck:node` | 仅 Node 端 |
| `pnpm typecheck:play` | 仅 Playground |
| `pnpm typecheck:vite-config` | 仅 Vite 配置 |
| `pnpm typecheck:vitest` | 仅测试配置 |

## 3. 测试体系

### 3.1 测试框架

- **Vitest** ^4.1.10 — 单元测试框架
- **@vue/test-utils** 2.4.6 — Vue 组件测试工具
- **happy-dom** — 轻量 DOM 环境
- **jsdom** 16.4.0 — 完整 DOM 环境
- **@vitest/coverage-v8** — 代码覆盖率

### 3.2 测试配置

```
vitest.config.mts    # 主测试配置
vitest.setup.ts      # 测试环境初始化
ssr-testing/vitest.config.ts  # SSR 测试配置
```

### 3.3 测试文件位置

- 组件测试：`packages/components/<component>/__tests__/`
- Hooks 测试：`packages/hooks/__tests__/`
- Utils 测试：`packages/utils/__tests__/`
- SSR 测试：`ssr-testing/cases/`（约 63 个 SSR 测试用例）

### 3.4 运行测试

| 命令 | 说明 |
|------|------|
| `pnpm test` | 运行所有测试 |
| `pnpm test:coverage` | 带覆盖率 |
| `pnpm test:ssr` | SSR 测试 |
| `pnpm test packages/components/button/__tests__/` | 运行指定测试 |

## 4. 代码质量工具

### 4.1 ESLint

- 配置文件：`eslint.config.mjs`
- 共享配置：`internal/eslint-config/`
- 检查范围：`.vue, .js, .ts, .jsx, .tsx, .md, .json`
- 支持 `--cache` 和 `--concurrency=auto`

### 4.2 Prettier

- 配置文件：`.prettierrc`
- 忽略文件：`.prettierignore`
- 格式化命令：`pnpm format`

### 4.3 Git Hooks

```
.husky/
├── pre-commit     # 提交前：lint-staged（ESLint + Prettier）
└── commit-msg     # 提交信息：commitlint 校验
```

**lint-staged 配置**：
```json
{
  "*.{vue,js,ts,jsx,tsx,md,json,scss}": [
    "eslint --fix --concurrency=auto",
    "prettier --write --experimental-cli"
  ]
}
```

### 4.4 Commit 规范

- 工具：`commitlint` + `czg`（commitizen adapter）
- 规范：Conventional Commits
- 命令：`pnpm cz` 交互式提交

## 5. 开发环境

### 5.1 Playground

```
play/
├── main.ts          # 入口，创建 Vue app 并挂载 Element Plus
```
