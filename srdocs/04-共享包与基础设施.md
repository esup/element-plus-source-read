# 共享包与基础设施

## 1. packages/hooks — 组合式函数（33 个）

Hooks 是 Element Plus 的核心逻辑层，将组件的通用行为抽取为可复用的组合式函数。

### 1.1 分类概览

#### 命名与样式
| Hook | 说明 | 使用场景 |
|------|------|----------|
| `useNamespace` | BEM 命名空间生成器 | **几乎所有组件**，生成 `el-button`、`el-button--primary` 等 class |
| `useSize` | 从 ConfigProvider 继承尺寸 | 表单组件、Button 等 |

#### 国际化
| Hook | 说明 |
|------|------|
| `useLocale` | 获取当前语言配置，提供 `t()` 翻译函数 |

#### 浮层与定位
| Hook | 说明 |
|------|------|
| `useFloating` | 基于 @floating-ui 的浮层定位 |
| `usePopper` | Popper 弹层管理 |
| `usePopperContainer` | Popper 容器管理 |
| `useTeleport` | Teleport 传送目标处理 |

#### 焦点与无障碍
| Hook | 说明 |
|------|------|
| `useFocus` | 元素焦点控制 |
| `useFocusController` | 焦点状态管理（focus/blur 回调） |
| `useTrapFocus` | 焦点陷阱（Dialog/Drawer 内） |
| `useAria` | ARIA 无障碍属性 |
| `useId` | 唯一 ID 生成（关联 label 与 input） |
| `useEscapeKeydown` | ESC 键监听（关闭弹层） |

#### 模态与遮罩
| Hook | 说明 |
|------|------|
| `useModal` | 模态框管理器（多弹窗堆叠） |
| `useLockscreen` | 打开弹窗时锁定 body 滚动 |
| `usePreventGlobal` | 阻止全局事件 |
| `useZIndex` | z-index 层级管理 |

#### 状态与模型
| Hook | 说明 |
|------|------|
| `useModelToggle` | v-model 显隐切换逻辑 |
| `useAttrs` | 透传 $attrs 处理 |
| `useProps` | 响应式 prop 访问 |
| `useEmptyValues` | 空值判断（支持自定义空值） |

#### 交互行为
| Hook | 说明 |
|------|------|
| `useDraggable` | 拖拽移动（Dialog 拖拽） |
| `useComposition` | 输入法组合状态（中文输入处理） |
| `useCursor` | 光标位置保持 |
| `useCalcInputWidth` | 输入框动态宽度计算 |

#### 渲染与性能
| Hook | 说明 |
|------|------|
| `useThrottleRender` | 节流渲染（大量数据分批显示） |
| `useIntermediateRender` | 中间渲染状态 |
| `useOrderedChildren` | 子组件顺序管理 |
| `useTransitionFallthrough` | 过渡动画穿透 |

#### 定时器
| Hook | 说明 |
|------|------|
| `useTimeout` | 定时器管理（自动清理） |
| `useDelayedToggle` | 延迟显示/隐藏 |

#### 其他
| Hook | 说明 |
|------|------|
| `useDeprecated` | 废弃 API 控制台警告 |
| `useForwardRef` | ref 转发给父组件 |
| `useSameTarget` | 判断事件源是否同一目标 |

### 1.2 核心 Hook 详解：useNamespace

`useNamespace` 是 BEM 命名系统的核心，几乎所有组件都依赖它：

```typescript
// 使用方式
const ns = useNamespace('button')

ns.b()                        // 'el-button'
ns.m('primary')               // 'el-button--primary'
ns.is('disabled')             // 'is-disabled'
ns.is('loading', true)        // 'is-loading'
ns.e('text')                  // 'el-button__text'
ns.em('text', 'expand')       // 'el-button__text--expand'
ns.be('text', 'expand')       // 'el-button-text__expand'
```

```
is-{state}                      → .is-disabled, .is-loading
```

```typescript

```

### 8.2 安装器架构

```
make-installer.ts
    │
    ├── components: Plugin[]   ← component.ts 中列出所有组件
    ├── plugins: Plugin[]      ← plugin.ts 中列出所有插件
    │
    └── install(app, options)
         ├── 防重复安装检查 (INSTALLED_KEY)
         ├── 遍历注册所有组件
         └── 注入全局配置 (ConfigProvider)
```
