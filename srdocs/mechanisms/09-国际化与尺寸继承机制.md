# 09 - 国际化与尺寸继承机制

## 概述

Element Plus 通过 `useLocale` hook 实现国际化翻译，通过 `useSize` hook 实现组件尺寸的层级继承。两者都依赖 ConfigProvider 的 provide/inject 机制。

## 国际化机制

### useLocale

**文件**: `packages/hooks/use-locale/index.ts`

```typescript
export const buildTranslator = (locale: MaybeRef<Language>): Translator =>
  (path, option) => translate(path, option, unref(locale))

export const translate = (path, option, locale) =>
  (get(locale, path, path) as string).replace(
    /\{(\w+)\}/g,
    (_, key) => `${option?.[key] ?? `{${key}}`}`
  )

export const buildLocaleContext = (locale: MaybeRef<Language>): LocaleContext => {
  const lang = computed(() => unref(locale).name)
  return {
    lang,
    locale: isRef(locale) ? locale : ref(locale),
    t: buildTranslator(locale),  // 翻译函数
  }
}

export const useLocale = (localeOverrides?) => {
  const locale = localeOverrides || inject(localeContextKey, ref())!
  return buildLocaleContext(computed(() => locale.value || English))  // 默认英文
}
```

### 语言包结构

```typescript
// packages/locale/lang/zh-cn.ts
export default {
  name: 'zh-cn',
  el: {
    colorpicker: { confirm: '确定', clear: '清空' },
    datepicker: { placeholder: '选择日期', now: '此刻', today: '今天' },
    pagination: { goto: '前往', pagesize: '条/页', total: '共 {total} 条' },
    table: { emptyText: '暂无数据', confirmFilter: '筛选' },
    // ... 每个组件的翻译文本
  }
}
```

### 翻译使用

```typescript
// 在组件中
const { t } = useLocale()
t('el.pagination.goto')  // → '前往'
t('el.pagination.total', { total: 100 })  // → '共 100 条'
```

### 语言切换

```vue

    <App />
  </el-config-provider>
</template>

<script setup>

```

## 尺寸继承机制

### useSize

**文件**: `packages/hooks/use-size/index.ts`

```typescript
export const useSizeProp = buildProp({
  type: String,
  values: componentSizes,  // ['large', 'default', 'small']
  required: false,
})

export const SIZE_INJECTION_KEY: InjectionKey<SizeContext> = Symbol('size')

export const useGlobalSize = () => {
  const injectedSize = inject(SIZE_INJECTION_KEY, {} as SizeContext)
  return computed<ComponentSize>(() => unref(injectedSize.size) || '')
}
```

### 尺寸继承链

```
ConfigProvider (size="small")
    ↓ provide SIZE_INJECTION_KEY
Form (size="large")
    ↓ provide SIZE_INJECTION_KEY (覆盖)
FormItem (size 从 Form 继承)
    ↓
Input / Select / Button 等
    ↓ useSize()
    ↓ 优先级: 自身 prop > FormItem > Form > ConfigProvider > 默认值
```

### 各组件中的尺寸解析

```typescript
// 典型组件中的尺寸解析
const _size = useSize(props.size, { formItem: true })
// 优先级: props.size > formItem.size > form.size > globalSize > ''
```

## useId — 唯一 ID 生成

**文件**: `packages/hooks/use-id/index.ts`

```typescript
const defaultIdInjection = {
  prefix: Math.floor(Math.random() * 10000),
  current: 0,
}

export const useId = (deterministicId?) => {
  const idInjection = useIdInjection()
  const namespace = useGetDerivedNamespace()

  return computedEager(() =>
    unref(deterministicId) ||
    `${namespace.value}-id-${idInjection.prefix}-${idInjection.current++}`
  )
}
```

生成的 ID 用于：
- `aria-labelledby` / `aria-describedby` 关联
- `label[for]` 与 `input[id]` 关联
- 弹层 `id` 属性

## useEmptyValues — 空值处理

**文件**: `packages/hooks/use-empty-values/index.ts`

```typescript
export const DEFAULT_EMPTY_VALUES = ['', undefined, null]
export const DEFAULT_VALUE_ON_CLEAR = undefined

export const useEmptyValues = (props, defaultValue?) => {
  const config = inject(emptyValuesContextKey, ref({}))

  const emptyValues = computed(
    () => props.emptyValues || config.value.emptyValues || DEFAULT_EMPTY_VALUES
  )

  const valueOnClear = computed(() => {
    if (isFunction(props.valueOnClear)) return props.valueOnClear()
    if (props.valueOnClear !== undefined) return props.valueOnClear
    if (isFunction(config.value.valueOnClear)) return config.value.valueOnClear()
    if (config.value.valueOnClear !== undefined) return config.value.valueOnClear
    return defaultValue !== undefined ? defaultValue : DEFAULT_VALUE_ON_CLEAR
  })

  const isEmptyValue = (value) => {
    if (isArray(value)) {
      return emptyValues.value.some((ev) => isEqual(value, ev))
    }
    return emptyValues.value.includes(value)
  }

  return { emptyValues, valueOnClear, isEmptyValue }
}
```

## 设计要点

| 机制 | 要点 |
|------|------|
| 国际化 | 基于 `lodash.get` 的路径访问 + 模板变量替换 |
| 默认语言 | 未配置时自动回退到英文 |
| 尺寸继承 | 通过 `SIZE_INJECTION_KEY` 逐层 provide/inject |
| 尺寸优先级 | 组件自身 > FormItem > Form > ConfigProvider > 默认 |
| ID 生成 | 随机前缀 + 递增计数器，SSR 需要手动 provide |
| 空值处理 | 支持自定义空值列表和清除时的返回值 |
