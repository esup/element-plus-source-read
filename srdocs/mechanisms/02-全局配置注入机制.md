# 02 - 全局配置注入机制

## 概述

Element Plus 通过 `ConfigProvider` 组件和 `provide/inject` 机制实现全局配置的层级传递，支持 locale、size、zIndex、namespace 等全局配置的动态注入与覆盖。

## 核心架构

```
ConfigProvider 组件
    ↓ provide()
provideGlobalConfig()
    ↓ provide 多个 context key
┌─────────────────────────────────────┐
│ configProviderContextKey (完整配置)  │
│ localeContextKey (语言)             │
│ namespaceContextKey (命名空间)      │
│ zIndexContextKey (z-index)          │
│ SIZE_INJECTION_KEY (尺寸)           │
│ emptyValuesContextKey (空值)        │
└─────────────────────────────────────┘
    ↓ inject
各组件通过 useGlobalConfig() / useLocale() / useSize() 等消费
```

## 核心源码

**文件**: `packages/components/config-provider/src/hooks/use-global-config.ts`

### provideGlobalConfig

```typescript
export const provideGlobalConfig = (
  config: MaybeRef<ConfigProviderContext>,
  app?: App,
  global = false
) => {
  const inSetup = !!getCurrentInstance()
  const oldConfig = inSetup ? useGlobalConfig() : undefined

  const provideFn = app?.provide ?? (inSetup ? provide : undefined)

  // 合并父级配置与当前配置（子配置覆盖父配置）
  const context = computed(() => {
    const cfg = unref(config)
    if (!oldConfig?.value) return cfg
    return mergeConfig(oldConfig.value, cfg)
  })

  // 分别 provide 各个配置项
  provideFn(configProviderContextKey, context)
  provideFn(localeContextKey, computed(() => context.value.locale))
  provideFn(namespaceContextKey, computed(() => context.value.namespace))
  provideFn(zIndexContextKey, computed(() => context.value.zIndex))
  provideFn(SIZE_INJECTION_KEY, {
    size: computed(() => context.value.size || ''),
  })
  provideFn(emptyValuesContextKey, computed(() => ({
    emptyValues: context.value.emptyValues,
    valueOnClear: context.value.valueOnClear,
  })))

  // 保存全局配置（用于函数式组件如 ElMessage）
  if (global || !globalConfig.value) {
    globalConfig.value = context.value
  }
  return context
}
```

### useGlobalConfig

```typescript
export function useGlobalConfig(key?, defaultValue?) {
  const config = getCurrentInstance()
    ? inject(configProviderContextKey, globalConfig)
    : globalConfig
  if (key) {
    return computed(() => config.value?.[key] ?? defaultValue)
  }
  return config
}
```

### useGlobalComponentSettings

为函数式组件（Message、Notification 等）提供完整的组件设置：

```typescript
export function useGlobalComponentSettings(block, sizeFallback?) {
  const config = useGlobalConfig()
  const ns = useNamespace(block, computed(() => config.value?.namespace))
  const locale = useLocale(computed(() => config.value?.locale))
  const zIndex = useZIndex(computed(() => config.value?.zIndex))
  const size = computed(() => unref(sizeFallback) || config.value?.size || '')
  provideGlobalConfig(computed(() => unref(config) || {}))
  return { ns, locale, zIndex, size }
}
```

## ConfigProvider 组件

**文件**: `packages/components/config-provider/src/config-provider.ts`

```typescript
export default defineComponent({
  name: 'ElConfigProvider',
  props: configProviderProps,
  setup(props, { slots }) {
    const config = provideGlobalConfig(props)
    // 同步 message 配置
    watch(() => props.message, (val) => {
      Object.assign(messageConfig, config?.value?.message ?? {}, val ?? {})
    }, { immediate: true, deep: true })
    return () => renderSlot(slots, 'default', { config: config?.value })
  },
})
```

## 配置项

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `locale` | `Language` | 语言包 |
| `size` | `'large' \| 'default' \| 'small'` | 全局组件尺寸 |
| `namespace` | `string` | CSS 命名空间前缀（默认 `'el'`） |
| `zIndex` | `number` | 全局初始 z-index |
| `a11y` | `boolean` | 无障碍支持 |
| `button` | `ButtonConfigContext` | 按钮配置 |
| `message` | `MessageConfigContext` | 消息配置 |
| `dialog` | `DialogConfigContext` | 对话框配置 |
| `table` | `TableConfigContext` | 表格配置 |
| `emptyValues` | `unknown[]` | 空值定义 |
| `valueOnClear` | `unknown` | 清除时的值 |

## 配置合并策略

```typescript
const mergeConfig = (a, b) => {
  const keys = [...new Set([...keysOf(a), ...keysOf(b)])]
  const obj = {}
  for (const key of keys) {
    obj[key] = b[key] !== undefined ? b[key] : a[key]  // 子配置优先
  }
  return obj
}
```

## 使用方式

```vue
<template>
  <el-config-provider :locale="zhCn" size="small" :z-index="2000">
    <App />
  </el-config-provider>
</template>
```

## 设计要点

| 要点 | 说明 |
|------|------|
| 层级继承 | 子 ConfigProvider 会与父配置合并，子配置优先 |
| 分离注入 | 各配置项独立 provide，组件可按需 inject |
| 函数式支持 | 通过 `globalConfig` ref 支持函数式组件获取配置 |
| 响应式 | 使用 `computed` 保证配置变更时自动更新 |
