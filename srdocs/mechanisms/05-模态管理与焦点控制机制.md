# 05 - 模态管理与焦点控制机制

## 概述

Element Plus 通过 `useModal`、`useLockscreen`、`useEscapeKeydown`、`FocusTrap` 组件和 `useZIndex` 五个子系统协作，实现了完整的多弹窗堆叠管理、滚动锁定、ESC 关闭和焦点陷阱。

## 核心架构

```
Dialog / Drawer 打开
    ↓
useZIndex → 分配 z-index
useModal → 压入模态栈
useLockscreen → 锁定 body 滚动
FocusTrap → 焦点陷阱激活
useEscapeKeydown → ESC 键监听
    ↓
关闭时反向操作
```

## useModal — 模态栈管理

**文件**: `packages/hooks/use-modal/index.ts`

```typescript
const modalStack: ModalInstance[] = []

const closeModal = (e: KeyboardEvent) => {
  if (modalStack.length === 0) return
  const code = getEventCode(e)
  if (code === EVENT_CODE.esc) {
    e.stopPropagation()
    const topModal = modalStack[modalStack.length - 1]  // 栈顶弹窗
    topModal.handleClose()  // 关闭最顶层弹窗
  }
}

export const useModal = (instance: ModalInstance, visibleRef: Ref<boolean>) => {
  watch(visibleRef, (val) => {
    if (val) {
      modalStack.push(instance)      // 打开 → 入栈
    } else {
      modalStack.splice(modalStack.indexOf(instance), 1)  // 关闭 → 出栈
    }
  })
}

// 全局 ESC 键监听（只注册一次）
if (isClient) useEventListener(document, 'keydown', closeModal)
```

## useLockscreen — 滚动锁定

**文件**: `packages/hooks/use-lockscreen/index.ts`

```typescript
export const useLockscreen = (trigger: Ref<boolean>, options = {}) => {
  const ns = options.ns || useNamespace('popup')
  const hiddenCls = computed(() => ns.bm('parent', 'hidden'))

  let scrollBarWidth = 0
  let withoutHiddenClass = false
  let bodyWidth = '0'

  watch(trigger, (val) => {
    if (!val) {
      // 恢复 body 样式
      if (withoutHiddenClass && document) {
        document.body.style.width = bodyWidth
        removeClass(document.body, hiddenCls.value)
      }
      return
    }

    // 记录原始状态
    withoutHiddenClass = !hasClass(document.body, hiddenCls.value)
    if (withoutHiddenClass) {
      bodyWidth = document.body.style.width
      addClass(document.body, hiddenCls.value)  // 添加隐藏滚动条 class
    }

    // 计算滚动条宽度并补偿
    scrollBarWidth = getScrollBarWidth(ns.namespace.value)
    if (scrollBarWidth > 0 && withoutHiddenClass) {
      document.body.style.width = `calc(100% - ${scrollBarWidth}px)`
    }
  })

  onScopeDispose(() => cleanup())
}
```

支持多层嵌套：只有最后一个弹窗关闭时才恢复 body 样式。

## useEscapeKeydown — ESC 键监听

**文件**: `packages/hooks/use-escape-keydown/index.ts`

```typescript
let registeredEscapeHandlers: ((e: KeyboardEvent) => void)[] = []

const cachedHandler = (event: KeyboardEvent) => {
  if (getEventCode(event) === EVENT_CODE.esc) {
    registeredEscapeHandlers.forEach((handler) => handler(event))
  }
}

export const useEscapeKeydown = (handler: (e: KeyboardEvent) => void) => {
  onMounted(() => {
    if (registeredEscapeHandlers.length === 0) {
      document.addEventListener('keydown', cachedHandler)  // 首次注册
    }
    registeredEscapeHandlers.push(handler)
  })

  onBeforeUnmount(() => {
    registeredEscapeHandlers = registeredEscapeHandlers.filter(h => h !== handler)
    if (registeredEscapeHandlers.length === 0) {
      document.removeEventListener('keydown', cachedHandler)  // 全部移除时取消监听
    }
  })
}
```

## useZIndex — z-index 管理

**文件**: `packages/hooks/use-z-index/index.ts`

```typescript
export const useZIndex = (zIndexOverrides?) => {
  const increasingInjection = getCurrentInstance()
    ? inject(ZINDEX_INJECTION_KEY, initial) : initial

  const initialZIndex = computed(() => {
    const zIndexFromInjection = unref(zIndexInjection)
    return isNumber(zIndexFromInjection) ? zIndexFromInjection : defaultInitialZIndex  // 2000
  })

  const currentZIndex = computed(() => initialZIndex.value + zIndex.value)

  const nextZIndex = () => {
    increasingInjection.current++
    zIndex.value = increasingInjection.current
    return currentZIndex.value
  }

  return { initialZIndex, currentZIndex, nextZIndex }
}
```

## FocusTrap — 焦点陷阱

**文件**: `packages/components/focus-trap/src/focus-trap.vue`

FocusTrap 确保焦点只能在弹层内部循环（Tab/Shift+Tab），不会逃逸到背后页面。

```typescript
// 核心逻辑
const onKeydown = (e: KeyboardEvent) => {
  const code = getEventCode(e)
  const isTabbing = code === EVENT_CODE.tab && !altKey && !ctrlKey && !metaKey

  if (isTabbing) {
    const [first, last] = getEdges(container)  // 获取第一个和最后一个可聚焦元素

    if (!shiftKey && currentFocusingEl === last) {
      // Tab 到最后一个 → 循环到第一个
      e.preventDefault()
      if (loop) tryFocus(first, true)
    } else if (shiftKey && [first, container].includes(currentFocusingEl)) {
      // Shift+Tab 到第一个 → 循环到最后一个
      e.preventDefault()
      if (loop) tryFocus(last, true)
    }
  }
}

// 焦点陷阱生命周期
async function startTrap() {
  focusableStack.push(focusLayer)  // 推入焦点层栈
  // 记录之前焦点的元素（关闭后恢复）
  lastFocusBeforeTrapped = document.activeElement
  // 聚焦到弹层内第一个可聚焦元素
  focusFirstDescendant(obtainAllFocusableElements(trapContainer))
}

function stopTrap() {
  // 恢复之前焦点
  tryFocus(lastFocusBeforeTrapped ?? document.body)
  focusableStack.remove(focusLayer)
}
```

## Dialog 中的综合应用

**文件**: `packages/components/dialog/src/use-dialog.ts`

```typescript
export const useDialog = (props, targetRef) => {
  const { nextZIndex } = useZIndex()           // z-index 管理
  const zIndex = ref(props.zIndex ?? nextZIndex())

  if (props.lockScroll) {
    useLockscreen(visible)                      // 滚动锁定
  }

  // 打开时
  function doOpen() {
    visible.value = true
    zIndex.value = props.zIndex ?? nextZIndex() // 分配新 z-index
  }

  // 关闭时
  function handleClose() {
    if (props.beforeClose) {
      props.beforeClose(hide)
    } else {
      close()
    }
  }

  // 带到前台（可穿透模式下）
  function bringToFront() {
    if (penetrable.value) zIndex.value = nextZIndex()
  }

  return { visible, zIndex, handleClose, bringToFront, ... }
}
```

## 设计要点

| 要点 | 说明 |
|------|------|
| 模态栈 | 全局 `modalStack` 管理多弹窗堆叠顺序 |
| ESC 关闭 | 只关闭栈顶弹窗，不影响其他 |
| 滚动锁定 | 支持嵌套弹窗，只在最后关闭时恢复 |
| z-index 递增 | 每次打开弹窗自动分配递增的 z-index |
| 焦点循环 | Tab/Shift+Tab 在弹层内循环 |
| 焦点恢复 | 关闭弹层后恢复到之前的焦点位置 |
| 焦点层栈 | `focusableStack` 支持嵌套焦点陷阱 |
