# 04 - 弹层定位与渲染机制

## 概述

Element Plus 的弹层系统基于 `@floating-ui/dom` 实现，通过 `useFloating` hook、`Popper` 组件、`useTeleport` hook 三层协作，完成弹层的定位、渲染和显隐控制。

## 核心架构

```
useFloating (定位计算)
    ↓
Popper 组件 (容器 + provide 上下文)
    ├── Trigger (触发器)
    ├── Content (弹层内容)
    └── Arrow (箭头)
    ↓
useTeleport (DOM 传送)
    ↓
useDelayedToggle (延迟显隐)
    ↓
useModelToggle (v-model 控制)
```

## useFloating — 浮层定位

**文件**: `packages/hooks/use-floating/index.ts`

```typescript
export const useFloating = ({ middleware, placement, strategy }) => {
  const referenceRef = ref<HTMLElement | VirtualElement>()  // 参考元素
  const contentRef = ref<HTMLElement>()                      // 弹层内容
  const x = ref<number>()
  const y = ref<number>()
  const middlewareData = ref({})

  const update = async () => {
    const referenceEl = unrefReference(referenceRef)
    const contentEl = unrefElement(contentRef)
    if (!referenceEl || !contentEl) return

    const data = await computePosition(referenceEl, contentEl, {
      placement: unref(placement),   // 放置位置
      strategy: unref(strategy),     // 定位策略 (absolute/fixed)
      middleware: unref(middleware),  // 中间件（箭头、偏移、翻转等）
    })

    // 更新状态
    keysOf(states).forEach((key) => { states[key].value = data[key] })
  }

  // 响应式自动更新
  onMounted(() => { watchEffect(() => { update() }) })

  return { x, y, placement, strategy, middlewareData, update, referenceRef, contentRef }
}
```

## useTeleport — DOM 传送

**文件**: `packages/hooks/use-teleport/index.ts`

```typescript
export const useTeleport = (
  contentRenderer: () => VNode,
  appendToBody: Ref<boolean>
) => {
  const isTeleportVisible = ref(false)
  let $el: HTMLElement | null = null

  const showTeleport = () => {
    isTeleportVisible.value = true
    if ($el !== null) return
    $el = createGlobalNode()  // 在 body 创建容器节点
  }

  const hideTeleport = () => {
    isTeleportVisible.value = false
    if ($el !== null) {
      removeGlobalNode($el)  // 清理容器节点
      $el = null
    }
  }

  const renderTeleport = () => {
    return appendToBody.value !== true
      ? contentRenderer()  // 不传送到 body，就地渲染
      : isTeleportVisible.value
        ? [h(Teleport, { to: $el }, contentRenderer())]  // 传送到 body
        : undefined
  }

  return { isTeleportVisible, showTeleport, hideTeleport, renderTeleport }
}
```

## useDelayedToggle — 延迟显隐

**文件**: `packages/hooks/use-delayed-toggle/index.ts`

```typescript
export const useDelayedToggle = ({ showAfter, hideAfter, autoClose, open, close }) => {
  const { registerTimeout } = useTimeout()
  const { registerTimeout: registerTimeoutForAutoClose, cancelTimeout } = useTimeout()

  const onOpen = (event?, delay = unref(showAfter)) => {
    registerTimeout(() => {
      open(event)
      if (isNumber(autoClose) && autoClose > 0) {
        registerTimeoutForAutoClose(() => close(event), autoClose)
      }
    }, delay)
  }

  const onClose = (event?, delay = unref(hideAfter)) => {
    cancelTimeout()
    registerTimeout(() => close(event), delay)
  }

  return { onOpen, onClose }
}
```

## Tooltip 组件 — 弹层系统的典型应用

**文件**: `packages/components/tooltip/src/tooltip.vue`

```typescript
// Tooltip 组合了所有弹层机制
const { show, hide } = useTooltipModelToggle({ indicator: open })
const { onOpen, onClose } = useDelayedToggle({
  showAfter, hideAfter, autoClose, open: show, close: hide,
})

// 向 Trigger 和 Content 子组件提供控制方法
provide(TOOLTIP_INJECTION_KEY, {
  controlled, id, open, trigger,
  onOpen, onClose,
  onToggle: (event?) => { open.value ? onClose(event) : onOpen(event) },
  updatePopper,
})
```

## 弹层组件层次关系

```
Tooltip (基础弹层)
├── TooltipTrigger → 处理 hover/click/focus 事件
├── TooltipContent → 渲染弹层内容 + 定位
└── Popper → 底层定位容器

Popover → 基于 Tooltip，自定义内容
Popconfirm → 基于 Popover，确认操作
Select → 基于 Tooltip + 虚拟化列表
Dropdown → 基于 Popper
Cascader → 基于 Popper
DatePicker → 基于 Popper
```

## 设计要点

| 要点 | 说明 |
|------|------|
| 定位与渲染分离 | `useFloating` 只负责计算位置，渲染由组件完成 |
| Teleport 延迟创建 | 弹层 DOM 仅在需要时创建，关闭时销毁 |
| 延迟切换 | 支持 showAfter/hideAfter/autoClose 精细控制 |
| 响应式更新 | 通过 `watchEffect` 自动响应尺寸/位置变化 |
| 虚拟触发 | 支持 `VirtualElement` 作为参考元素 |
