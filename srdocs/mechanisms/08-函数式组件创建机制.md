# 08 - 函数式组件创建机制

## 概述

Element Plus 的 `Message`、`Notification`、`MessageBox` 等组件采用函数式调用方式创建，通过 `createVNode` + `render` 在运行时动态生成 Vue 组件实例，无需在模板中声明即可使用。

## 核心源码

**文件**: `packages/components/message/src/method.ts`

### 消息创建流程

```typescript
let seed = 1  // 自增 ID

const createMessage = (options, context?) => {
  const id = `message_${seed++}`
  const container = document.createElement('div')

  const props = {
    ...options,
    id,
    onClose: () => { userOnClose?.(); closeMessage(instance) },
    onDestroy: () => { render(null, container) },  // 清理 DOM
  }

  // 创建 VNode
  const vnode = createVNode(
    MessageConstructor,
    props,
    isFunction(props.message) || isVNode(props.message)
      ? { default: isFunction(props.message) ? props.message : () => props.message }
      : null
  )

  // 注入 app context（继承全局配置）
  vnode.appContext = context || message._context

  // 渲染到容器
  render(vnode, container)
  appendTo.appendChild(container.firstElementChild!)

  return { id, vnode, vm: vnode.component!, handler, props }
}
```

### 主函数

```typescript
const message = (options = {}, context?) => {
  if (!isClient) return { close: () => undefined }

  const normalized = normalizeOptions(options)
  const instances = getOrCreatePlacementInstances(normalized.placement)

  // 消息去重（grouping 模式）
  if (normalized.grouping && instances.length) {
    const instance = instances.find(({ vnode }) => vnode.props?.message === normalized.message)
    if (instance) {
      instance.props.repeatNum! += 1  // 增加计数
      return instance.handler
    }
  }

  // 最大数量限制
  if (isNumber(messageConfig.max) && instances.length >= messageConfig.max) {
    return { close: () => undefined }
  }

  const instance = createMessage(normalized, context)
  instances.push(instance)
  return instance.handler
}

// 快捷方法
messageTypes.forEach((type) => {
  message[type] = (options = {}, appContext) => {
    return message({ ...normalizeOptions(options), type }, appContext)
  }
})
```

## 安装与 Context 传递

```typescript
// packages/utils/vue/install.ts
export const withInstallFunction = <T>(fn: T, name: string) => {
  ;(fn as SFCWithInstall<T>).install = (app: App) => {
    ;(fn as SFCInstallWithContext<T>)._context = app._context  // 保存 app context
    app.config.globalProperties[name] = fn
  }
  return fn as SFCInstallWithContext<T>
}
```

这样 `ElMessage` 在函数调用时可以通过 `_context` 获取 ConfigProvider 注入的全局配置。

## 实例管理

```typescript
// 按 placement 分组管理实例
const placementInstances: Record<string, MessageContext[]> = {}

// 关闭消息
const closeMessage = (instance: MessageContext) => {
  const placement = instance.props.placement
  const instances = placementInstances[placement]
  instances.splice(instances.indexOf(instance), 1)
  instance.handler.close()
}

// 关闭所有
export function closeAll(type?: MessageType) {
  for (const placement in placementInstances) {
    const instances = [...placementInstances[placement]]
    for (const instance of instances) {
      if (!type || type === instance.props.type) {
        instance.handler.close()
      }
    }
  }
}
```

## 使用方式

```typescript
// 基础调用
ElMessage('Hello World')
ElMessage({ message: 'Hello', type: 'success' })
ElMessage.success('操作成功')
ElMessage.error('操作失败')

// 高级配置
ElMessage({
  message: h('strong', '自定义内容'),  // 支持 VNode
  type: 'warning',
  duration: 5000,
  showClose: true,
  grouping: true,  // 相同消息去重
  appendTo: '#container',  // 挂载目标
  onClose: () => console.log('closed'),
})

// 关闭所有
ElMessage.closeAll()
ElMessage.closeAllByPlacement('top')
```

## Notification 类似实现

Notification 与 Message 实现模式相同，区别在于：
- 支持 title + message + type
- 支持 position（top-right/top-left/bottom-right/bottom-left）
- 更丰富的内容展示

## 设计要点

| 要点 | 说明 |
|------|------|
| 动态创建 | 通过 `createVNode` + `render` 动态创建组件 |
| Context 继承 | 通过 `vnode.appContext` 继承全局配置 |
| 消息去重 | `grouping` 模式下相同消息只增加计数 |
| 数量限制 | `max` 配置限制同时显示的消息数 |
| 内存管理 | 关闭时 `render(null, container)` 清理 DOM |
| 按位置分组 | 不同 placement 的消息独立管理堆叠 |
| 类型安全 | 完整的 TypeScript 类型定义 |
