# 06 - 表单验证机制

## 概述

Element Plus 的表单验证系统基于 `async-validator` 库，通过 `Form` 和 `FormItem` 的 `provide/inject` 协作，实现了声明式校验、触发式校验、表单重置等完整功能。

## 核心架构

```
Form (form.vue)
├── provide(formContextKey) → 提供 model, rules, emit
├── fields[] → 收集所有 FormItem 上下文
├── validate() → 遍历所有字段校验
├── resetFields() → 遍历所有字段重置
└── clearValidate() → 遍历所有字段清除

FormItem (form-item.vue)
├── inject(formContextKey) → 获取 model, rules
├── provide(formItemContextKey) → 提供 validate, resetField
├── normalizedRules → 合并 Form 级 + Item 级 rules
├── doValidate() → 使用 async-validator 执行校验
└── 显示/隐藏错误信息
```

## Form 组件

**文件**: `packages/components/form/src/form.vue`

### 字段收集

```typescript
const fields = reactive<FormItemContext[]>([])

const addField: FormContext['addField'] = (field) => {
  if (!fields.includes(field)) {
    fields.push(field)
  }
  // 保存初始值（用于 resetFields）
  if (field.propString) {
    initialValues.set(field.propString, cloneDeep(field.fieldValue))
  }
}

const removeField: FormContext['removeField'] = (field) => {
  fields.splice(fields.indexOf(field), 1)
}
```

### 全局校验

```typescript
const validate = async (callback?) => validateField(undefined, callback)

const doValidateField = async (props = []) => {
  const fields = obtainValidateFields(props)
  let validationErrors = {}

  for (const field of fields) {
    try {
      await field.validate('')
      if (field.validateState === 'error' && !field.error) field.resetField()
    } catch (fields) {
      validationErrors = { ...validationErrors, ...fields }
    }
  }

  if (Object.keys(validationErrors).length === 0) return true
  return Promise.reject(validationErrors)
}
```

## FormItem 组件

**文件**: `packages/components/form/src/form-item.vue`

### 规则合并

```typescript
const normalizedRules = computed(() => {
  const rules: FormItemRule[] = []

  // 1. Item 自身 rules
  if (props.rules) rules.push(...ensureArray(props.rules))

  // 2. Form 级 rules（按 prop 路径提取）
  if (formContext?.rules && props.prop) {
    const _rules = getProp(formContext.rules, props.prop).value
    if (_rules) rules.push(...ensureArray(_rules))
  }

  // 3. required prop 覆盖
  if (required !== undefined) { /* 合并 required 到已有规则 */ }

  return rules
})
```

### 执行校验

```typescript
const doValidate = async (rules: RuleItem[]): Promise<true> => {
  const modelName = propString.value
  const validator = new AsyncValidator({
    [modelName]: rules,
  })
  return validator
    .validate({ [modelName]: fieldValue.value }, { firstFields: true })
    .then(() => {
      onValidationSucceeded()
      return true
    })
    .catch((err) => {
      onValidationFailed(err)
      return Promise.reject(err)
    })
}

const validate = async (trigger, callback) => {
  if (isResettingField || !props.prop) return false

  const rules = getFilteredRule(trigger)  // 按触发器过滤规则
  if (rules.length === 0) { callback?.(true); return true }

  setValidationState('validating')
  return doValidate(rules)
    .then(() => { callback?.(true); return true })
    .catch((err) => { callback?.(false, err); return false })
}
```

### 触发器过滤

```typescript
const getFilteredRule = (trigger: string) => {
  return normalizedRules.value
    .filter((rule) => {
      if (!rule.trigger || !trigger) return true
      if (isArray(rule.trigger)) return rule.trigger.includes(trigger)
      return rule.trigger === trigger
    })
    .map(({ trigger, ...rule }) => rule)  // 移除 trigger 字段
}
```

### 字段重置

```typescript
const resetField = async () => {
  const model = formContext?.model
  if (!model || !props.prop) return

  isResettingField = true  // 防止重置时触发校验
  getProp(model, props.prop).value = cloneDeep(initialValue)
  await nextTick()
  clearValidate()
  isResettingField = false
}
```

## 数据流

```
用户输入 → 触发 change/blur 事件
    ↓
FormItem.validate('change' | 'blur')
    ↓
getFilteredRule(trigger) → 过滤匹配的 rules
    ↓
new AsyncValidator(descriptor).validate(model)
    ↓
成功 → validateState = 'success'
失败 → validateState = 'error', validateMessage = 错误信息
    ↓
Form.emit('validate', prop, isValid, message)
```

## 设计要点

| 要点 | 说明 |
|------|------|
| 规则合并 | Form 级 + Item 级 rules 自动合并 |
| 触发器过滤 | 支持 `blur`/`change` 触发器精确匹配 |
| 嵌套路径 | 支持 `prop="user.name"` 深层路径访问 |
| 初始值管理 | `setInitialValues` 支持动态设置重置基准值 |
| 校验状态 | `validating` / `success` / `error` 三态 |
| 防抖显示 | 错误信息使用 `refDebounced(100ms)` 延迟显示 |
| 异步校验 | 基于 `async-validator` 的 Promise 校验 |
| 滚动到错误 | `scrollToError` 自动滚动到第一个错误字段 |
