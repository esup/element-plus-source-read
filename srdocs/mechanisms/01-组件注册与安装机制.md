# 01 - 组件注册与安装机制

## 概述

Element Plus 通过 `withInstall` 系列工具函数，将每个 Vue 组件包装为标准的 Vue 插件，支持全局注册和按需引入两种使用方式。

## 核心源码

**文件**: `packages/utils/vue/install.ts`

### withInstall - 组件注册

```typescript
export const withInstall = <T, E extends Record<string, any>>(
  main: T,
  extra?: E
) => {
  // 为组件添加 install 方法
  ;(main as SFCWithInstall<T>).install = (app): void => {
    for (const comp of [main, ...Object.values(extra ?? {})]) {
      app.component(comp.name, comp)
    }
  }

  // 将附加组件挂载到主组件上（如 Button.Group）
  if (extra) {
    for (const [key, comp] of Object.entries(extra)) {
      ;(main as any)[key] = comp
    }
  }

  // 添加 props 默认值设置器
  withPropsDefaultsSetter(main)
  return main as SFCWithInstall<T> & E
}
```

### withInstallFunction - 函数式组件注册

```typescript
export const withInstallFunction = <T>(fn: T, name: string) => {
  ;(fn as SFCWithInstall<T>).install = (app: App) => {
    // 保存 app context，用于函数式调用时获取全局配置
    ;(fn as SFCInstallWithContext<T>)._context = app._context
    app.config.globalProperties[name] = fn
  }
  return fn as SFCInstallWithContext<T>
}
```

用于 `Message`、`Notification`、`MessageBox` 等函数式调用的组件。

### withInstallDirective - 指令注册

```typescript
export const withInstallDirective = <T extends Directive>(
  directive: T,
  name: string
) => {
  ;(directive as SFCWithInstall<T>).install = (app: App): void => {
    app.directive(name, directive)
  }
  return directive as SFCWithInstall<T>
}
```

用于 `v-click-outside`、`v-repeat-click` 等自定义指令。

### withNoopInstall - 空操作注册

```typescript
export const withNoopInstall = <T>(component: T) => {
  ;(component as SFCWithInstall<T>).install = NOOP
  withPropsDefaultsSetter(main)
  return component as SFCWithInstall<T>
}
```

用于子组件（如 `ButtonGroup`），它们不需要独立注册，但需要满足插件接口。

## 使用示例

以 Button 组件为例：

```typescript
// packages/components/button/index.ts
import { withInstall, withNoopInstall } from '@element-plus/utils'
import Button from './src/button.vue'
import ButtonGroup from './src/button-group.vue'

export const ElButton = withInstall(Button, { ButtonGroup })
export const ElButtonGroup = withNoopInstall(ButtonGroup)
export default ElButton
```

- `ElButton` 注册时会同时注册 `ButtonGroup`，并挂载为 `ElButton.ButtonGroup`
- `ElButtonGroup` 自身是空操作安装（已通过 Button 注册）

## 全局安装流程

```typescript
// packages/element-plus/make-installer.ts
export const makeInstaller = (components: Plugin[] = []) => {
  const install = (app: App, options?: ConfigProviderContext) => {
    if (app[INSTALLED_KEY]) return  // 防止重复安装
    app[INSTALLED_KEY] = true
    components.forEach((c) => app.use(c))  // 逐一注册
    if (options) provideGlobalConfig(options, app, true)  // 注入全局配置
  }
  return { version, install }
}
```

## 设计要点

| 要点 | 说明 |
|------|------|
| 幂等安装 | 通过 `INSTALLED_KEY` 标记防止重复安装 |
| 子组件绑定 | 通过 `extra` 参数将子组件挂载到主组件 |
| 按需引入 | 每个组件独立导出，支持 `app.use(ElButton)` 单独注册 |
| Props 默认值 | `withPropsDefaultsSetter` 允许外部覆盖组件 props 默认值 |
