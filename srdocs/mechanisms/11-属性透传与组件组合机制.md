# 11 - 属性透传与组件组合机制

## 概述

Element Plus 通过 `useAttrs`、`useForwardRef`、`useOrderedChildren`、`useThrottleRender` 等 hook 实现了组件间的属性透传、ref 转发、子组件排序和性能优化。

## useAttrs — 属性过滤透传

**文件**: `packages/hooks/use-attrs/index.ts`

```typescript
const DEFAULT_EXCLUDE_KEYS = ['class', 'style']
const LISTENER_PREFIX = /^on[A-Z]/

export const useAttrs = (params: Params = {}) => {
  const { excludeListeners = false, excludeKeys } = params
  const allExcludeKeys = computed(() =>
    (excludeKeys?.value || []).concat(DEFAULT_EXCLUDE_KEYS)
  )

  const instance = getCurrentInstance()

  return computed(() =>
    fromPairs(
      Object.entries(instance.proxy?.$attrs!).filter(
        ([key]) =>
          !allExcludeKeys.value.includes(key) &&
          !(excludeListeners && LISTENER_PREFIX.test(key))
      )
    )
  )
}
```

**使用场景**: 将父组件透传的属性（排除 class/style/事件）绑定到内部元素

## useForwardRef — ref 转发

**文件**: `packages/hooks/use-forward-ref/index.ts`

```typescript
export const useForwardRef = <T>(forwardRef: Ref<T | null>) => {
  const setForwardRef = ((el: T) => { forwardRef.value = el }) as ForwardRefSetter

  provide(FORWARD_REF_INJECTION_KEY, { setForwardRef })
}

export const useForwardRefDirective = (setForwardRef): ObjectDirective => {
  return {
    mounted(el) { setForwardRef(el) },
    updated(el) { setForwardRef(el) },
    unmounted() { setForwardRef(null) },
  }
}
```

**使用场景**: 包装组件时让外部能获取到内部真实 DOM 元素

## useOrderedChildren — 子组件排序

**文件**: `packages/hooks/use-ordered-children/index.ts`

```typescript
export const useOrderedChildren = <T extends ChildEssential>(
  vm: ComponentInternalInstance,
  childComponentName: string
) => {
  const children = shallowRef<Record<number, T>>({})
  const orderedChildren = shallowRef<T[]>([])

  const addChild = (child: T) => {
    children.value[child.uid] = child
    triggerRef(children)
    // 拦截 insertBefore 以检测 DOM 顺序变化
    onMounted(() => {
      const parentNode = child.getVnode().el!.parentNode!
      const originalFn = parentNode.insertBefore.bind(parentNode)
      parentNode.insertBefore = (node, anchor) => {
        const shouldSort = nodesMap.get(parentNode)!.some(el => node === el || anchor === el)
        if (shouldSort) triggerRef(children)
        return originalFn(node, anchor)
      }
    })
  }

  const sortChildren = () => {
    orderedChildren.value = getOrderedChildren(vm, childComponentName, children.value)
  }

  return { children: orderedChildren, addChild, removeChild, ChildrenSorter }
}
```

**使用场景**: Tabs、Steps、Breadcrumb 等需要按 DOM 顺序排列子组件的场景

## useThrottleRender — 节流渲染

**文件**: `packages/hooks/use-throttle-render/index.ts`

```typescript
export const useThrottleRender = (loading: Ref<boolean>, throttle = 0) => {
  if (throttle === 0) return loading
  const throttled = ref(initVal)

  const dispatchThrottling = (timer) => {
    timeoutHandle = setTimeout(() => { throttled.value = loading.value }, timer)
  }

  watch(() => loading.value, (val) => {
    dispatcher(val ? 'leading' : 'trailing')
  })

  return throttled
}
```

**使用场景**: Skeleton 组件的加载状态节流显示，避免快速加载时的闪烁

## useDelayedRender — 延迟渲染

**文件**: `packages/hooks/use-intermediate-render/index.ts`

```typescript
export const useDelayedRender = ({
  indicator,              // 目标显隐状态
  intermediateIndicator,  // 中间状态
  shouldSetIntermediate,
  beforeShow, afterShow, beforeHide, afterHide,
}) => {
  watch(() => unref(indicator), (val) => {
    if (val) {
      beforeShow?.()
      nextTick(() => {
        if (shouldSetIntermediate('show')) intermediateIndicator.value = true
      })
    } else {
      beforeHide?.()
      nextTick(() => {
        if (shouldSetIntermediate('hide')) intermediateIndicator.value = false
      })
    }
  })
}
```

**使用场景**: 弹层组件的过渡动画（先渲染内容，再触发过渡）

## useCalcInputWidth — 输入框动态宽度

**文件**: `packages/hooks/use-calc-input-width/index.ts`

```typescript
export function useCalcInputWidth() {
  const calculatorRef = shallowRef<HTMLElement>()
  const calculatorWidth = ref(0)

  const inputStyle = computed(() => ({
    minWidth: `${Math.max(calculatorWidth.value, MINIMUM_INPUT_WIDTH)}px`,
  }))

  useResizeObserver(calculatorRef, resetCalculatorWidth)

  return { calculatorRef, calculatorWidth, inputStyle }
}
```

**使用场景**: Select 组件中输入框宽度根据内容自适应

## 组件组合模式总结

### provide/inject 模式

Element Plus 大量使用 provide/inject 进行父子组件通信：

```
ConfigProvider → 全局配置
Form → FormItem → 表单字段
Tooltip → Trigger/Content → 弹层控制
Popper → Trigger/Content/Arrow → 弹层引用
Tabs → TabPane → 标签页管理
Table → TableColumn → 表格列管理
```

### 组件分层模式

```
外层组件 (如 Tooltip)
├── 提供控制上下文 (provide)
├── 管理显隐状态
├── 处理延迟逻辑
│
├── Trigger 子组件
│   └── inject 控制方法
│   └── 处理用户交互事件
│
└── Content 子组件
    └── inject 控制方法
    └── 渲染内容 + 定位
```

## 设计要点

| 要点 | 说明 |
|------|------|
| 属性过滤 | 自动排除 class/style，可选排除事件监听器 |
| ref 转发 | 通过 provide/inject + 指令实现跨层级 ref 传递 |
| DOM 顺序感知 | 拦截 insertBefore 检测子组件顺序变化 |
| 渲染节流 | 避免快速状态切换导致的视觉闪烁 |
| 延迟渲染 | 确保过渡动画的中间状态正确 |
| 宽度自适应 | ResizeObserver 监听内容变化动态调整宽度 |
