# 10 - 指令系统与事件处理机制

## 概述

Element Plus 提供了 4 个自定义指令和多个事件处理 hook，用于处理点击外部检测、重复点击、焦点陷阱、鼠标滚轮标准化等场景。

## 自定义指令

### v-click-outside — 点击外部检测

**文件**: `packages/directives/click-outside/index.ts`

```typescript
const nodeList: FlushList = new Map()

// 全局事件监听（只注册一次）
if (isClient) {
  let startClick: MouseEvent | undefined
  document.addEventListener('mousedown', (e) => (startClick = e))
  document.addEventListener('mouseup', (e) => {
    if (startClick) {
      for (const handlers of nodeList.values()) {
        for (const { documentHandler } of handlers) {
          documentHandler(e, startClick)
        }
      }
      startClick = undefined
    }
  })
}

// 创建处理器
function createDocumentHandler(el, binding) {
  return function (mouseup, mousedown) {
    const isContainedByEl = el.contains(mouseup.target) || el.contains(mousedown.target)
    const isContainedByPopper = popperRef?.contains(mouseup.target)
    // 点击在元素外部 → 触发回调
    if (!isContainedByEl && !isContainedByPopper) {
      binding.value(mouseup, mousedown)
    }
  }
}

const ClickOutside: ObjectDirective = {
  beforeMount(el, binding) { nodeList.set(el, [...]) },
  updated(el, binding) { /* 更新处理器 */ },
  unmounted(el) { nodeList.delete(el) },  // 清理
}
```

**使用组件**: Select, Dropdown, Popover, Popconfirm, ColorPicker 等

## 事件处理 Hooks

### useSameTarget — 同一目标点击检测

**文件**: `packages/hooks/use-same-target/index.ts`

```typescript
export const useSameTarget = (handleClick?) => {
  if (!handleClick) return { onClick: NOOP, onMousedown: NOOP, onMouseup: NOOP }

  let mousedownTarget = false
  let mouseupTarget = false

  const onClick = (e) => {
    // 只有 mousedown 和 mouseup 都在同一元素上才触发 click
    if (mousedownTarget && mouseupTarget) handleClick(e)
    mousedownTarget = mouseupTarget = false
  }
  const onMousedown = (e) => { mousedownTarget = e.target === e.currentTarget }
  const onMouseup = (e) => { mouseupTarget = e.target === e.currentTarget }

  return { onClick, onMousedown, onMouseup }
}
```

**使用场景**: Dialog 的遮罩层点击关闭（防止拖拽到遮罩层上误触发关闭）

### usePreventGlobal — 全局事件阻止

**文件**: `packages/hooks/use-prevent-global/index.ts`

```typescript
export const usePreventGlobal = <E extends keyof DocumentEventMap>(
  indicator: Ref<boolean>,
  evt: E,
  cb: (e: DocumentEventMap[E]) => boolean
) => {
  const prevent = (e) => { if (cb(e)) e.stopImmediatePropagation() }
  watch(() => indicator.value, (val) => {
    if (val) stop = useEventListener(document, evt, prevent, true)
    else stop?.()
  }, { immediate: true })
}
```

### useFocusController — 焦点控制器

**文件**: `packages/hooks/use-focus-controller/index.ts`

```typescript
export function useFocusController<T extends { focus: () => void }>(
  target: ShallowRef<T | undefined>,
  { disabled, beforeFocus, afterFocus, beforeBlur, afterBlur } = {}
) {
  const isFocused = ref(false)

  const handleFocus = (event) => {
    const cancelFocus = beforeFocus?.(event) ?? false
    if (disabled || isFocused.value || cancelFocus) return
    isFocused.value = true
    emit('focus', event)
    afterFocus?.()
  }

  const handleBlur = (event) => {
    const cancelBlur = beforeBlur?.(event) ?? false
    if (disabled || (event.relatedTarget && wrapperRef.value?.contains(event.relatedTarget)) || cancelBlur) return
    isFocused.value = false
    emit('blur', event)
    afterBlur?.()
  }

  return { isFocused, wrapperRef, handleFocus, handleBlur }
}
```

## 输入处理 Hooks

### useComposition — 输入法组合处理

**文件**: `packages/hooks/use-composition/index.ts`

```typescript
export function useComposition({ afterComposition, emit }) {
  const isComposing = ref(false)

  const handleCompositionEnd = (event) => {
    if (isComposing.value) {
      isComposing.value = false
      nextTick(() => afterComposition(event))  // 组合结束后触发回调
    }
  }

  return { isComposing, handleComposition, handleCompositionStart, handleCompositionEnd }
}
```

**使用场景**: Input 组件在中文输入时不触发 `input` 事件

### useCursor — 光标位置保持

**文件**: `packages/hooks/use-cursor/index.ts`

```typescript
export function useCursor(input: ShallowRef<HTMLInputElement | undefined>) {
  let selectionInfo: SelectionInfo

  function recordCursor() {
    // 记录当前光标位置和前后文本
    const { selectionStart, selectionEnd, value } = input.value
    selectionInfo = { selectionStart, selectionEnd, value, beforeTxt, afterTxt }
  }

  function setCursor() {
    // 根据 formatter 处理后的文本恢复光标位置
    let startPos = value.length
    if (value.endsWith(afterTxt)) startPos = value.length - afterTxt.length
    else if (value.startsWith(beforeTxt)) startPos = beforeTxt.length
    input.value.setSelectionRange(startPos, startPos)
  }

  return [recordCursor, setCursor]
}
```

**使用场景**: Input 组件的 `formatter` 属性处理后保持光标位置

### useDraggable — 拖拽移动

**文件**: `packages/hooks/use-draggable/index.ts`

```typescript
export const useDraggable = (targetRef, dragRef, draggable, overflow?) => {
  const isDragging = ref(false)

  const onMousedown = (e) => {
    const onMousemove = (e) => {
      const moveX = offsetX + e.clientX - downX
      const moveY = offsetY + e.clientY - downY
      if (!overflow?.value) {
        moveX = clamp(moveX, minLeft, maxLeft)  // 边界限制
        moveY = clamp(moveY, minTop, maxTop)
      }
      targetRef.value.style.transform = `translate(${moveX}px, ${moveY}px)`
    }
    document.addEventListener('mousemove', onMousemove)
    document.addEventListener('mouseup', onMouseup)
  }

  return { isDragging, resetPosition, updatePosition }
}
```

**使用场景**: Dialog 组件的 `draggable` 属性

## 设计要点

| 要点 | 说明 |
|------|------|
| 全局事件单例 | ClickOutside 和 ESC 监听只注册一次，通过 Map 管理多个处理器 |
| 内存安全 | 指令 unmounted 时自动清理引用 |
| 输入法感知 | 中文输入过程中不触发校验/搜索 |
| 光标保持 | formatter 处理后自动恢复光标位置 |
| 拖拽边界 | 可选的溢出控制（是否允许拖出视口） |
| 焦点生命周期 | beforeFocus/afterFocus/beforeBlur/afterBlur 完整钩子 |
