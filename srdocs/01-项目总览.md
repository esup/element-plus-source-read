# Element Plus 项目总览

## 1. 项目简介

**Element Plus** 是一个基于 **Vue 3** 的开源 UI 组件库，使用 **TypeScript** 编写。它是经典 Element UI 的 Vue 3 版本重写，提供了丰富的高质量组件，广泛用于中后台系统开发。

- **GitHub**: https://github.com/element-plus/element-plus
- **官网**: https://element-plus.org
- **许可证**: MIT
- **Node 要求**: >= 22.13.0
- **包管理器**: pnpm 11.13.0
- **核心框架**: Vue 3.5.25
- **类型系统**: TypeScript ~6.0.3

## 2. 仓库类型

本项目是一个 **pnpm workspace monorepo**，包含以下工作区：

| 工作区 | 路径 | 说明 |
|--------|------|------|
| `packages/*` | 核心包 | 组件、hooks、utils、主题等 |
| `docs` | 文档站 | VitePress 驱动的文档站点 |
| `play` | 游乐场 | 本地开发调试环境 |
| `internal/*` | 内部工具 | 构建、元数据、lint 配置等 |

## 3. 技术栈一览

| 类别 | 技术 | 版本 |

| 框架 | Vue 3 | 3.5.25 |

## 4. 核心依赖关系

```
element-plus (主入口包)
├── @element-plus/components   → 所有 UI 组件
├── @element-plus/hooks        → 组合式函数
├── @element-plus/utils        → 工具函数
├── @element-plus/constants    → 常量定义
├── @element-plus/directives   → 自定义指令
├── @element-plus/locale       → 国际化
├── @element-plus/theme-chalk  → SCSS 主题样式
├── @element-plus/test-utils   → 测试工具
├── @element-plus/icons-vue    → 图标库
└── 第三方: dayjs, lodash-es, @vueuse/core, @floating-ui/dom, async-validator
```

## 5. 安装与启动命令

| 命令 | 说明 |
|------|------|
| `pnpm install` | 安装依赖 |
| `pnpm dev` | 启动 playground 开发服务器 |
| `pnpm docs:dev` | 启动文档站点 |
| `pnpm test` | 运行所有测试 |
| `pnpm build` | 构建生产产物 |
| `pnpm build:theme` | 仅构建主题样式 |
| `pnpm lint` | 代码检查 |
| `pnpm typecheck` | 类型检查 |
| `pnpm format` | 代码格式化 |

## 6. 项目规模

- **组件数量**: 约 91 个独立组件包
- **Hooks 数量**: 33 个组合式函数
- **指令数量**: 4 个自定义指令 (ClickOutside, RepeatClick, TrapFocus, Mousewheel)
- **国际化语言**: 约 68 种语言支持
- **主题样式文件**: 每个组件对应独立 SCSS 文件
