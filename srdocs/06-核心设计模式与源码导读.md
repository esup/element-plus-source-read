# 核心设计模式与源码导读

## 1. 组件设计模式

### 1.1 SFC + Script Setup 模式

所有组件使用 Vue 3 `<script setup>` 语法，搭配 `defineOptions` 声明组件名：

```vue
<script lang="ts" setup>
defineOptions({ name: 'ElXxx' })
const props = withDefaults(defineProps<XxxProps>(), { /* defaults */ })
const emit = defineEmits(xxxEmits)
// ... 逻辑
defineExpose({ /* 暴露给外部的 API */ })
</script>
```

### 1.2 Props/Emits 分离定义

Props 类型定义在独立的 `.ts` 文件中，与 `.vue` 模板分离：

```
button/
├── button.vue       # 模板 + 逻辑
├── button.ts        # Props 接口 + Emits 定义
└── use-button.ts    # 组合式逻辑
```

### 1.3 Composable 逻辑分离

组件的业务逻辑抽取到 `use-xxx.ts` 组合式函数中，保持 `.vue` 文件简洁：

```vue
<!-- button.vue -->
<script setup>
const { _ref, _size, _type, handleClick } = useButton(props, emit)
const buttonStyle = useButtonCustomStyle(props)
</script>
```

## 5. 设计原则总结

1. **组合优于继承** — 通过 hooks 组合功能，而非继承
2. **关注点分离** — Props 类型、模板、逻辑分文件
3. **渐进式注册** — withInstall 支持全局/按需注册
4. **BEM 严格规范** — useNamespace 统一命名
5. **provide/inject** — 父子组件通信的主要方式
6. **CSS 变量** — 主题定制通过 CSS 自定义属性实现
7. **TypeScript 优先** — 所有 API 都有完整类型定义
8. **虚拟化** — 大数据场景提供 V2 版本
9. **无障碍** — useAria + FocusTrap 支持 A11y
10. **国际化** — 68 种语言，ConfigProvider 注入
